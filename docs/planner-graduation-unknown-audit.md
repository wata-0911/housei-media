# 卒業要件 unknown / unsupported 総監査（2026）

## 結論

`graduationCheckComplete` は引き続き **false**。この画面は部分進捗であり、卒業可否を判定・保証しない。

今回、安全に自動評価へ加えたのは、構造化済みの `full_course_credits_required` と `min_courses` の組合せだけである。単位数だけでなく、mapping の `curriculumCredits` を満たした異なるカリキュラム科目数も満たす必要がある。したがって、法律学科の「選択必修 8科目32単位」は、32単位だけでは達成にならない。

`before`、卒論選択、段階的な振替、個別開講回数、スクーリング除外などは意味を実装していない限り allowlist に入れていない。値のない `required_course`（卒論指導等）は、0単位・1科目に読み替えず判定保留のままである。

## Source-first 確認

`shiori202646-61.pdf` を再確認済み。PDF内のページ表記で、法46-47、日本文学48-51、史学52-53、地理54-55、経済57、商業59を確認した（抽出PDFの物理ページは3-16）。主な再確認事項は以下。

- 法47: 選択必修は科目構成単位を満たす8科目32単位。達成後のみ未完成スクーリング2単位等を算入可能。
- 日本文学48-51: 3コースはいずれも必修20、選択必修20以上、選択24以上、卒論8。卒論第1・第2次指導が前提。
- 史学52-53: 史学演習は修得順で1-4を割り当てる。卒論指導は手続き・前提。
- 地理54-55: 現地研究・演習・特講の振替は回数・順序・上限を伴う。
- 経済57・商業59: 選択必修超過の選択算入、卒論の事前指導、特講・演習・公開科目の上限を確認。

## unsupported 40件の扱い

- 現PlannerStateだけでは評価不能: 卒論・履修前提・修得順・個別開講回数の情報が必要なもの。
- catalog構造化で将来評価可能性あり: 公式の対象mapping、回数・順序・全単位完了の契約を追加できるもの。ただし今回、推測から structured 化はしていない。
- 古い課程・移行措置・例外: 72件/scope相当の理由に現れる旧課程追加措置。正本の対象外なので現行判定に混在させない。
- 教職・資格など卒業要件外: `outside_mapping_scope` の開講および関連警告。卒業単位に算入しないが、勝手に消去もしない。

## UI 方針

通常カードには自動評価可能な進捗だけを表示する。unknown は同一理由で集約された「自動判定できない要件」欄に残るため、390pxでも同じ理由のカードが連続せず、情報も隠れない。理由は「単位要件として未判定」「mapping未特定」「ユーザー確認（卒論選択・修得順等）」として読める状態を維持する。

## 次に安全に進める条件

`before` や guidance を自動評価するには、PlannerStateに「指導完了」の明示記録を追加し、公式の手続きページ（法70、日本文74、経済・商業79等）まで契約化してから行う。地理の段階的振替と経済・商業の卒論内訳も、sourceとcatalog mappingの両方が揃うまで unknown を維持する。
