# 科目コード表: 照合に必要な行の抜粋

冊子 p.199-213 / PDF p.201-215。p.199-202の本科生・選科生表と、教職課程表を分ける。コードは5桁文字列で先頭0を保持。S申し込みコードはこの表とは別（p.199）。現catalogのsubjectCode（例HIS300TE）やclassCodeは同じnamespaceではない。

表番号tはページ上の抽出罫線表の順（sidebar表を含む）、行rは見出し以降の物理行。抽出器が最終列の右罫線欠落を理由に空欄としたp.199-203のコードは、原行bboxと画像で列を回復した。`∅`は結合セル/空欄。全行の構造は[JSON](official-codes.json)にrawCellsとheaderMatrixを保持。ここでは監査対象科目と一致する578行だけを転載し、その他の教職固有科目は収録しない。

教職の必修◎/選択必修○/選択△、新法/旧法、学科・免許教科列の意味を本科生Placementへ転用しない。p.204見出しの新旧法原則対象年も、学生の課程自動確定には使わない。p.213は次ページへ続くため、教職表全体の監査完了とはしない。
