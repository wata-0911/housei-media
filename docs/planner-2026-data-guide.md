# 成績取込・バックアップ復元の案内

2026年度版は法政通信メディアの `/planner` で公開を準備しています。正式公開と利用できる操作はサイトの案内をご確認ください。法政大学の公式サービスではありません。大学の成績表に載る記録と、ご自身が記録した履修計画・進捗は区別して表示します。

## 大学の成績を取り込む

1. ご自身で大学のWeb学習サービスにログインし、成績表を開きます。「成績JSONの取得方法」に従い、成績表を開いた画面でBookmarkletを実行します。
2. コピーできたことを確認し、プランナーの「成績データを取り込む」を開きます。「JSONを貼り付け」で「読み込み・検証」を押すか、対応する成績JSONを「JSONファイル」から選びます。
3. 対象と内容をプレビューで確認したうえで、進める場合はご自身で反映します。照合が済んでいない成績や本人の学習進捗から、大学による認定結果を確定することはできません。

## 保存とファイルの使い分け

| ファイル | 用途 |
| --- | --- |
| 成績取込JSON | プランナーの成績取込欄で内容を確認して取り込みます。 |
| 全データのバックアップ | 対応する形式をバックアップ／復元欄で使います。利用中の画面で書き出せる形式を選んでください。 |
| 原文・退避データの保護ファイル | 元の記録を保全するために手元へ残します。通常のバックアップとして復元欄に選ばないでください。 |
| 復元前の保護ファイル | 確定前に復元先の原文を保全するためのものです。画面の指定に従い、今回の操作で保存したファイルを再選択します。 |

## 移行・復元する

1. 現在の記録と元ファイルを保全します。別のタブで編集中の場合は入力内容を確認し、閉じるか作業を終えてから進めてください。
2. 対応する通常バックアップを選び、差分の種類と件数を確認します。「対象原文の保護ファイルを保存」を押し、最初に選んだ通常バックアップと保存した保護ファイルをそれぞれ指定欄で再選択します。「全バイトを照合」を押してください。
3. 内容が一致し、保存・復元が可能と画面で確認できた場合だけ確定してください。復元で置き換わる記録はプレビューに従います。ブラウザで別のパスを開くだけで、自動移行・自動復元は行われません。
4. 保留・不一致の表示が出たら、画面の案内に従って原文を保存し、状態を確認してください。元ファイルやサイトデータを先に削除しないでください。編集中の成績入力が変わると古い復元同意が失効し、下書きは残ります。変更内容を見直してから必要な操作をやり直してください。

成績・進捗が含まれるファイルを共有する前に内容と保存先を確認してください。詳しくは [プライバシーポリシー](https://hosei-tsukyo-media.com/privacy#planner-guide) をご覧ください。
