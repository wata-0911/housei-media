## カタログ監査と記録方法

- snapshot: 686 offerings / 502 mappings。
- 上限ルール: 8件（上表6学科＋文学部3コース）、すべて`max_enrollments: 8`・`value: 16`・対象名`（他学部・他学科公開科目）`として`requirements`にある。
- 公開科目専用のoffering属性・mapping属性・mapping ID: **0件**。
- `mapping`は所属学科の教育課程表上の算入先（category / field / requirementType）を保存するが、表の行ラベル「（他学部・他学科公開科目）」は保持していない。
- `faculty` / `department`が所属と異なるだけのofferingは多数あり、通常の学科横断mapping、名称のないメディア・スクーリング開講、教職由来の候補が混在する。その差分を公開科目とみなすことはしない。
- `outside_mapping_scope`（30 opening）は対象化しない。manual / official mapping overrideも変更しない。

公開される実科目は年度・スクーリング時期で変わり得る（法律学特講だけが公開される回などがある）。そのため、686件の2026 catalogから公開科目を固定mappingで推測しない。利用者が実際に履修した科目名を「公開科目」として明示追加する、catalogと分離したユーザー所有レコード方式にする。

各レコードは科目名、履修状態、予定年度、期を保存し、単位は常に**2単位**である。`earned`だけを卒業所要単位に算入し、最大8回・16単位までを選択所属の専門教育「選択」へ流し込む。`planned` / `in_progress`は公開科目カードの参考値であり、`waiting` / `failed` / `dropped`は集計しない。9件目以降も実修得単位として専門教育の区分別集計には残るが、卒業算入外として表示する。

この8回・16単位の総枠は、自学部・自学科の総合特講や各種特講の上限とは独立である。同じ実開講を通常のcatalog科目と公開科目の両方に登録すると二重記録になるため、どちらか一方だけを追加する。
