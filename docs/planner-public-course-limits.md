日本語学・日本文学・日本芸能文化の各コースについても印刷48頁に同じ8科目・16単位の上限が構造化済みだが、本featureの専門教育カード対象は上表の6学科である。

公開科目欄はスクーリング欄に置かれている。ただし、この記述は受講可否や個々の開講の公開指定を列挙しておらず、開講のスクーリング属性だけで公開科目とは判定しない。

## カタログ監査

- snapshot: 686 offerings / 502 mappings。
- 上限ルール: 8件（上表6学科＋文学部3コース）、すべて`max_enrollments: 8`・`value: 16`・対象名`（他学部・他学科公開科目）`として`requirements`にある。
- 公開科目専用のoffering属性・mapping属性・mapping ID: **0件**。
- `mapping`は所属学科の教育課程表上の算入先（category / field / requirementType）を保存するが、表の行ラベル「（他学部・他学科公開科目）」は保持していない。
- `faculty` / `department`が所属と異なるだけのofferingは多数あり、通常の学科横断mapping、名称のないメディア・スクーリング開講、教職由来の候補が混在する。その差分を公開科目とみなすことはしない。
- `outside_mapping_scope`（30 opening）は対象化しない。manual / official mapping overrideも変更しない。

## 実装上の識別方法

`src/planner/publicCourseRules.ts`は、`OFFICIAL_PUBLIC_COURSE_MAPPING_IDS_2026`に**原典以外の公式公開科目一覧との照合で確認したmapping IDだけ**を登録する方式にした。空のregistryは「0単位」と誤表示せず、卒業要件カードを判定保留にする。

将来registryにIDが入れば、同一offeringにduplicate mapping edgeがあっても1科目・1回だけ数える。`earned`のみを卒業算入に使い、`planned` / `in_progress`は参考値、`waiting` / `failed` / `dropped`は無視する。8科目と16単位の両方を適用し、上限を超えた修得単位は実修得として残しつつ卒業算入外として表示する。4単位科目等で残り単位を越える場合は、科目を部分算入しない。

## 未解決ケース

個別の「公開」指定とcatalog mapping IDの公式対応表が、この16頁の抜粋にもsnapshotにもない。そのため現featureでは次を意図的に未知のまま残す。

- 現在の686開講のうち、どれが実際に他学部・他学科公開科目として開講されたか。
- 同一学部内の他学科と他学部の個別開講リスト。
- 個別開講ごとの公開指定以外の受講条件。
- 教職科目を公開科目と区別する公式ID対応。

この対応表が得られるまで、所属差分・`outside_mapping_scope`・手動overrideからの推測は行わない。
