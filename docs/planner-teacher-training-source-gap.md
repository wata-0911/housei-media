# 教職科目を通常卒業要件へ算入するための資料ギャップ

## 現時点の扱い

2026年カタログで `outside_mapping_scope` とされた教職等30開講は、通常の卒業要件進捗へ加算しない。`【教職】政治学` など残る `manual_review` も、所属別の算入先を推定しない。この扱いは「算入不可」という判定ではなく、根拠不足による判定保留である。

## 追加で必要な公式資料

1. 2026年度の通信教育部・教職課程「教育職員免許状取得の手引き」全文。免許種・教科・入学区分別の適用年度を確認できるもの。
2. 教職課程の科目一覧。科目名、科目コード、単位、授業形態、必修・選択、教育職員免許法施行規則上の区分が載った公式表。
3. 教職科目の卒業所要単位への算入規則。通常の学部・学科科目として算入できる上限、自由科目扱い、卒業単位外となる科目、スクーリング単位への算入可否を明記したもの。
4. `【教職】政治学` のような教職向け開講と、通常カリキュラムの同名・対応科目との公式な対応表。科目読替、代替、重複履修、単位の二重使用の可否を含むもの。
5. 学部・学科・コース別の教員免許状要件表。取得可能な免許種・教科ごとの必要科目と必要単位を確認できるもの。
6. 入学区分・編入学・既修得単位認定に関する教職課程の規則。認定済み教職単位が免許要件と卒業要件のどちらへ反映されるかを確認できるもの。
7. 教育実習、介護等体験、教職実践演習などの履修前提・履修順・実施条件を示す公式資料。
8. 年度をまたぐ科目名称・コード変更の新旧対照表。2026年度開講と適用カリキュラム上の科目を安定して結び付けるために必要。

これらが揃うまで、教職科目の免許要件進捗と通常卒業要件進捗は別の評価領域として保持する。
