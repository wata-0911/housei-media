# 履修計画のCSV・画像出力

履修計画のCSVとPNGは、ログインなしでこの端末のブラウザ内だけで生成する。履修データや画像をサーバーへ送信しない。

## 共通モデル

`plannerExportPresentation` は、現在の履修計画にあるcatalog科目と公開科目だけを、`1年 → 2年 → 3年 → 4年 → 未設定` の順で出力用行へ変換する純粋関数である。通信・メディア・評価のorphan stateは計画に存在しないため出力しない。CSVとPNGはこの同じモデルを使い、所属、年度、学年、時期、履修形態、状態、進捗、最終評価、区分が食い違わないようにする。出力操作はPlannerStateを変更しない。

通信の行には必要リポート数、合格リポート数、単位修得試験評価、既存の通信判定ロジックによる通信学習分の判定を追加する。必要リポート数が不明な場合は分母を補わず、判定不可のままとする。メディアの行には設定済みの総回数、動画・テスト完了数、ユーザーが登録したassessment概要だけを追加する。14回、15回、未設定のいずれもそのまま出力し、試験有無・日程を推測しない。

## CSV

CSVには、所属、計画年度、履修学年、履修時期、科目名、単位、履修形態、履修状態、進捗、最終評価、区分、catalog / 公開科目に加え、通信・メディアの補助列を出力する。UTF-8 BOMを付け、Excelで日本語を読み取りやすくする。セルはRFC4180相当で、カンマ、改行、ダブルクォートを含む場合に引用符で囲み、内部の引用符を二重化する。ファイル名は `hosei-planner-YYYY-MM-DD.csv` である。

## PNG

PNGは履修計画画面全体のスクリーンショットではなく、出力専用のプレゼンテーションから作る。所属と出力日を表示し、学年ごとに、科目名、単位、履修形態、時期、状態、進捗、最終評価、必要なassessment概要を並べる。編集用のselectや削除ボタン、卒業要件は含めない。長い科目名・assessmentは折り返し、行数に応じて画像の高さが自然に増える。最終評価・時期が未設定のPNG表示は `—` とする。
