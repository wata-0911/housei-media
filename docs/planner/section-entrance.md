## 調査と配置

| 領域 | 現在のマウント構造 | 配置判断 |
| --- | --- | --- |
| タイトル・単位サマリー | ページと共にマウント、集計更新では再レンダリング | #120 / #165の既存演出を維持。外枠に含めず二重演出を避ける |
| 注意事項・利用案内 | タブや保存と独立して常設 | 既存divを共通Motionコンポーネントに置換 |
| 科目検索・履修／修得一覧・出力・バックアップ | annualタブでのみマウント | タブ条件分岐の外側に常設の外枠を1つ追加 |
| 成績取り込み | annual内のdetails。開閉状態を親が保持 | 同じ常設外枠に含め、開閉・プレビューに演出を付けない |
| 履修／修得一覧・成績取り込み・卒論手続 | importEpochがkey。取り込み・復元などで再マウント | 外枠をkeyの外に置く。既存keyを維持 |
| 卒業要件の部分進捗・卒論手続 | annual内。所属による条件付き表示。下部にありスクロールで到達 | 同じ常設外枠に含め、条件変化やスクロール到達ごとの独立演出は追加しない |
| メディア進捗・プロフィール設定 | タブ切り替えで再マウント。内部の入力／保存・共有モーダルは独自状態 | 同じ常設外枠に含め、最初の切り替えも即時表示 |
| 保存状況・エラー・復旧案内 | 状態による条件付き表示 | 演出外に維持して即座に読めるようにする |

タブ内に個別のwhileInViewを置くと、viewport.onceでもタブやimportEpochによる再マウントで履歴が失われる。
安全策として**全タブ共通の常設外枠**で登場を管理する。タブ領域の先頭が初めて画面内に入ったとき、領域全体を一度だけ表示する。
科目検索、一覧、取り込み、部分進捗、メディア、プロフィールはこの外枠の対象。
各内部セクションがスクロールで現れるたびに個別に登場する方式ではない。
個別化のための訪問履歴・状態管理・タブの常時マウント化は追加しない。

#150で変わる可能性が高い一覧の内部カード・行・履修レコードには一切依存しない。
子コンポーネントのprops、key、条件分岐、イベント処理、入力／保存／フォーカス処理は維持する。

## 演出とアクセシビリティ

`PlannerSectionEntrance`でopacity 0→1、y 20→0、0.4秒easeOut、delayなし。
Home / Q&Aと同じフェード＋軽い縦移動。操作量の多い画面なので時間差を付けず短くする。
`whileInView` / `viewport.once: true`。高さのあるタブ領域でも先頭の進入で反応するようamountはsome。
ページを離れて再訪すれば初回演出を再実行するが、タブ・保存・取り込み・復元・モーダル開閉では外枠をマウントし直さない。

#165と同じ`useReducedMotion`によりreduce時はinitial=false、duration=0、delay=0。
画面外でもopacity 0を初期付与せず、IntersectionObserverを待たず内容を読める。
既存ボタンのhover / focus-visible / disabledは変更しない。
#165に記載の通り、OS設定を切り替える比較は各設定でページを再読み込みする。
